Formulario — Etapa 1 — Onboarding Prometheo // Variables y Smart Tags para BETROX

Descripción del formulario

Este formulario nos ayuda a definir cómo debe interpretar, ordenar y priorizar Prometheo las conversaciones comerciales y operativas de BETROX.

Vamos a trabajar sobre dos capas:

• Variables
 ◦ Son datos estructurales y únicos por lead, consulta o pedido.
◦ Sirven para segmentar, medir, priorizar y ordenar el embudo comercial.
◦ Ejemplos: categoría de producto, modelo de interés, medida, color, tipo de cliente, ticket estimado, ciudad de entrega, etapa del lead.

• Smart Tags / Etiquetas inteligentes
 ◦ Son temas, necesidades o situaciones que pueden coexistir dentro de una misma conversación.
◦ Sirven para detectar patrones, activar automatizaciones y ordenar mejor la operación comercial.
◦ Ejemplos: pide envío + consulta plazo + quiere showroom + objeción por precio + proyecto a medida.

Con esta información vamos a poder configurar mejor el CRM, el agente conversacional, la calificación de leads, las derivaciones humanas y las automatizaciones comerciales.
