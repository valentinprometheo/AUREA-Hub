# interface-design (vendored)

Community skill by Damola Akinleye — MIT License.
Source: https://github.com/Dammyjay93/interface-design
Vendored into this repo so it's available when building per-client dashboards
(e.g. DRAKON) alongside `aurea-dashboard-design`.

- `interface-design` → craft, visual hierarchy, tokens, states, design-system memory.
- Commands: `/interface-design:design-review`, `/interface-design:design-deslop`.
- Pairs with `aurea-dashboard-design` (brand + data doctrine) — brand rules win on
  palette, type and sphere; interface-design governs craft, hierarchy and states.
