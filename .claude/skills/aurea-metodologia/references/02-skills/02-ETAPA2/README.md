# 02-ETAPA2 — Skills de la Etapa 2 (Diseño del Agente Inteligente)

Skills que operan la Etapa 2: desde la preparación previa al diseño hasta la iteración del
agente con el cliente.

| Skill | Rol en la Etapa 2 |
|---|---|
| `prometheo-etapa2-design/` | Orquestadora — genera los 3 outputs del diseño (DOCX CRM, Prompt, Refactorización) |
| `prometheo-drive-audit-real-estate/` | Pre-Etapa 2 — auditoría del Drive del cliente desarrollista, documento "Matching y Difusión" |
| `prometheo-crm-graphics/` | Genera los gráficos SVG del DOCX de diseño del CRM |
| `prometheo-diseno-agente-ia-feedback/` | Fase de iteración — genera el Documento de Feedback de demo para que el cliente marque correcciones del agente |

**Se complementan con:** las skills verticales de `00-TRANSVERSAL/` (aportan la lógica del
rubro al diseño).
